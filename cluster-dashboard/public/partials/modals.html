İşlem Günlüğü:
İşlem başlatılıyor...

Proxmox Web GUI'de sunucunuza tıklayıp sağ üstteki >_ Shell butonuna basın ve aşağıdaki komut bloğunu yapıştırın:

VMware vCenter için Canonical tarafından resmi olarak optimize edilmiş ve open-vm-tools + Cloud-Init gömülü vSphere OVA şablonu kullanılır.

https://cloud-images.ubuntu.com/jammy/current/jammy-server-cloudimg-amd64.ova

vCenter'a 2 Dakikada Nasıl Eklenir?

  1. vCenter Web Client'ta cluster veya ESXi host'unuza sağ tıklayın: "Deploy OVF Template..."
  2. Açılan pencerede URL kutucuğuna yukarıdaki linki yapıştırın (Bilgisayarınıza indirmenize gerek yoktur, vCenter doğrudan çeker).
  3. Sanal makineye isim verin (Örn: ubuntu-2204-template) ve hedef Datastore'u seçip tamamlayın.
  4. Dağıtım bitince sanal makineye sağ tıklayın: Template → Convert to Template deyin.
